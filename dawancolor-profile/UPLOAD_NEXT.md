# Finish the profile from Android

This branch is a safe staging area. The NextBorder main branch and production site were not changed.

To complete the portrait and motion media:
1. Open the repository branch `dawancolor-profile-preview`.
2. Open the `dawancolor-profile/assets/` folder.
3. Upload `portrait-original.jpg` and `type-motion.gif` from the supplied design ZIP.
4. Edit `dawancolor-profile/README.md` and add the portrait image near the top with: `![Ishak Dawan](assets/portrait-original.jpg)`.

The GitHub connector can publish UTF-8 text and SVG files, but this session's available GitHub write action does not upload binary JPG/GIF files. No fake or substitute portrait was used.
